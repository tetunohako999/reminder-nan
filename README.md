# リマインダーなん？

予定の時間を知らせてくれる Windows 用のリマインダーアプリです。キャラクターが出てきます。

> **公式の配布ページは https://reminder-nan.pages.dev です。** アプリは、そのページか、このページの「Releases」からだけダウンロードしてください。ほかの場所で配られているものは、偽物の可能性があります。

## ダウンロード

1. 配布ページ（https://reminder-nan.pages.dev）の「ダウンロード」のボタンを押します。このページの [最新のリリース](https://github.com/tetunohako999/reminder-nan/releases/latest) の「Assets」にある `ReminderNan-Setup-<版の番号>.exe` も、同じファイルです。
2. ダウンロードする前に、[利用規約](LICENSE.txt) を読んでください。ダウンロード・インストールした時点で、利用規約に同意したものとします。

### 本物か確かめる（おすすめ）

配布ページとリリースのページに、インストーラーの SHA-256（ファイルの指紋）を書いています。PowerShell で次のように実行して（ファイル名の版の番号は、ダウンロードしたものに合わせてください）、出た値が同じか比べてください。値が違うときは、実行せずに削除してください。

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\ReminderNan-Setup-1.0.0.exe"
```

配布してくれた人から、別のメッセージで同じ値を受け取っている場合は、そちらとも比べるとより確かです。

## できること

- 予定を登録すると、その時間に Windows の通知が出ます。キャラクターも吹き出しで知らせます。
- 毎日・毎週などのくりかえしや、5 分前・10 分前・1 日前のお知らせもできます。
- キャラクターがデスクトップを歩き回ります。その場に留まることもできます。トレイに入れられます。
- Gemini API キーを設定すると、キャラクターと会話できます。会話で予定を登録したり、天気を聞いたりもできます。キーがなくても、ほかの機能はすべて使えます。

## 動く環境

- Windows 11（Windows 10 でも動く見込みです）
- インターネットは、会話と天気を使うときだけ使います。

## インストール

1. 上の「ダウンロード」の手順で、インストーラー（`ReminderNan-Setup-<版の番号>.exe`）をダウンロードします。
2. ダブルクリックして実行します。「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。このアプリには有料の電子署名を付けていないため、この画面が出ます。
3. 利用規約が表示されるので、読んで「同意する」を押します。
4. 誰のために入れるかを選ぶ画面では、そのまま（自分だけ）で進めます。この場合、管理者の権限は要りません。
5. インストールが終わったら「完了」を押すと、アプリが起動します。スタートメニューとデスクトップに「リマインダーなん？」ができます。

## 使い方

ほとんどの操作は、キャラクターを右クリックして出るメニューから行います。

### 起動と終了

- 終わるときは、右クリック →「終了する」。キャラクターが扉から出ていってから終わります。
- 同時に起動できるのは 1 つだけです。動いているときにもう一度起動すると、隠れていたキャラクターが出てきます。
- パソコンを起動したときに、自動では起動しません。自動で起動したいときは、スタートメニューの「リマインダーなん？」を右クリック →「詳細」→「ファイルの場所を開く」で出てくるショートカットを、`Win + R` で「shell:startup」と入力して開くフォルダにコピーしてください。

### キャラクターとのふれあい

- **つまむ**: ドラッグで持ち上げて、離すと落ちます。ほかのアプリのウィンドウの上で離すと、その上に乗ります。
- **なでる**: キャラクターの上で、マウスを左右に往復させます。
- **ごはん**: 右クリック →「ごはんをあげる」。約 2 時間半ごはんをあげないと、おなかをすかせます。おなかがいっぱいのときにあげると怒ります。
- **ピン留め**: 右クリック →「ピン留め」で、その場所から動かなくなります（宙にも留まります）。「ピンを外す」で元に戻ります。
- **眠る**: 約 5 分マウスを動かさないと眠ります。マウスを動かすと起きます。
- キャラクターは起動のたびに決まり、途中で入れ替わることもあります。自分で選ぶことはできません。
- おなかのすき具合などの数値は、画面に出しません。キャラクターの様子とセリフで伝えます。

### 予定（リマインダー）

- 右クリック →「リマインダー…」で一覧のウィンドウが開きます。「なにを」と「いつ」を入れて「追加」を押します。
- 「くりかえし」で毎日・毎週・毎月・毎年に、「前もってお知らせ」で 5 分前・10 分前・1 日前にも知らせるようにできます。
- 時間になると、キャラクターが吹き出しで知らせます。吹き出しは、ボタンを押すまで残ります。「あとで」を押すと、少したってからもう一度知らせます。
- アプリを閉じていた間やパソコンのスリープ中に時間が過ぎた予定は、次に起動したとき（スリープから戻ったとき）に知らせます。
- 起動すると、今日のこのあとの予定を教えてくれます。確認していない予定があると、30 分ごとに教えてくれます。
- 知らせ終わった予定は、7 日間一覧に残ってから消えます。
- Windows の集中モードの間は通知が出ませんが、吹き出しは出ます。

### 観測ノート

- 右クリック →「観測ノート…」で開きます。3 人が見せたモーションや出来事が、記録されていきます。まだ見ていないものは「？」です。
- たくさん集めると「感謝の証」が開きます。

### 隠す（タスクトレイ）

- 右クリック →「隠れる（タスクトレイへ）」、またはタスクトレイのアイコンを左クリックすると、キャラクターが隠れます。もう一度アイコンを左クリックすると出てきます。
- 隠れている間も、予定の時間には画面の右下に顔を出して知らせます。おなかも減りません。
- トレイのアイコンに赤い「！」が付いているときは確認していない予定が、緑の「！」のときは今日このあと予定があります。
- Windows 11 では、新しいアイコンは最初「^」の中に入ります。タスクバーへドラッグして出しておくと便利です。

## 会話（Gemini API キーが必要）

- 右クリック →「話しかける」で会話のウィンドウが開きます。キャラクターがそれぞれの口調で答えます。
- 会話で予定も登録できます（例:「明日の朝 10 時に会議」）。キャラクターが聞き返すので、「登録する」を押すか「うん」と答えると登録されます。確認なしに登録されることはありません。
- 「今日の予定教えて」と言うと、一覧を開いて教えてくれます。
- 「設定…」→「天気の地域」で地域を選んでおくと、「今日の天気は？」「傘いる？」などと聞いたときに答えます。
- Gemini に送るのは 1 日 200 回までです（日本時間の 0 時に戻ります）。
- 会話の中身は、アプリを閉じると消えます。パソコンには保存しません。

### API キーの設定

1. [Google AI Studio](https://aistudio.google.com/) で API キーを発行します（Google アカウントが必要です）。
2. キャラクターを右クリック →「設定…」を開き、キーを貼り付けます。
3. 「18 歳以上で、Gemini API の利用規約に同意しています」にチェックを入れて、「保存」を押します。規約は「Gemini API の利用規約を開く」で読めます。

### 気をつけてほしいこと

- **18 歳以上の方だけ**が使えます（Google の規約）。規約には「開発者が仕事・事業の目的で使うためのもの」という趣旨の記載もあるので、内容を確かめてから使ってください。
- **ヨーロッパ（EEA）・スイス・英国**では、有料枠のキーが必要です。
- **無料枠**（カードを登録していない状態）では、送った内容が Google の製品の改善に使われたり、人が読んだりすることがあります。**名前・住所・電話番号・パスワード・仕事の情報など、人に見られて困ることは書かないでください。** 気になるときは、Google Cloud で請求先を設定して有料枠にしてください（有料枠では改善に使われません）。料金は利用者の負担です。
- **キーは人に教えないでください。** あわせて、次のこともおすすめします。
  - Google Cloud コンソールの「API とサービス」→「認証情報」で、キーの「API の制限」を「Generative Language API」（Gemini API）だけにする
  - 有料枠にしたときは、Google Cloud で予算アラートを設定する（アラートは知らせるだけで、使いすぎを止めはしません）
  - 漏れたかもしれないときは、AI Studio でキーを削除して作り直し、設定し直す
- キーは、このパソコンの中に Windows の仕組み（DPAPI）で暗号化して保存します。作者に送ることはありません。ただし、この暗号化は、同じ Windows ユーザーで動くほかのソフトからは守れません。上の制限をしておくと、万一のときの被害を小さくできます。出どころの分からないソフトや、パソコンを操作できる AI ツールに、むやみに権限を与えないことも大事です。
- このアプリが使う Gemini のモデルは、「設定…」→「使っているモデルについて」で見られます。Google がこれらのモデルの提供を終えると、会話は使えなくなります。そのときは、設定からキーを削除し、AI Studio でもキーを削除してください。

## 保存するもの・アンインストール

- 予定・観測ノート・設定・動作の記録（ログ）は、`%APPDATA%\desktop-pet` に保存します（エクスプローラーのアドレス欄に貼ると開けます）。API キーは暗号化して保存します。どれも作者には送りません。
- 動作の記録は `%APPDATA%\desktop-pet\logs\pet.log` です。API キーや会話の中身は書きません。不具合を知らせてもらうときの手がかりになります。
- アンインストールは、Windows の「設定」→「アプリ」→「インストールされているアプリ」で「リマインダーなん？」を選びます。
- **アンインストールすると、保存したデータ（予定・観測ノート・設定・API キー）も消えます。** 残しておきたいときは、先に `%APPDATA%\desktop-pet` をフォルダごと別の場所にコピーしておいてください（入れ直したあとに戻すと、そのまま使えます）。新しい版を上書きでインストールするときは消えません。
- 会話をもう使わないときは、Google AI Studio でもキーを削除してください。

## キャラクターの絵と動きについて
