「リマインダーなん？」利用規約

この規約は、Windows 用のアプリ「リマインダーなん？」（以下「このアプリ」）を使うときの約束です。このアプリをインストールしたとき、または使ったときに、この規約に同意したものとします。

1. 使ってよいこと

  • 個人で使う場合にかぎり、このアプリを無料で使えます。
  • このアプリが動いている画面を撮った画像や動画を、SNS などに載せるのは自由です。
  • 配布ページへのリンクを紹介するのは自由です。

2. してはいけないこと

  • このアプリやその一部を、ほかの人に配ったり、インターネット上に置いたりすること（再配布）
  • このアプリやその一部を売ること、お金を取って提供すること
  • このアプリを作り変えたものを配ること
  • このアプリに入っている絵・動画・文章（キャラクターのセリフなど）を取り出して、ほかのことに使うこと

3. 会話機能（Gemini API）

  • 会話機能を使うには、利用者が自分で発行した Google の Gemini API キーが必要です。
  • 会話機能は、Google の「Gemini API 利用規約」に従って使ってください。その規約により、18 歳以上の方だけが使えます。
  • 会話で入力した文章と、返事を作るのに必要な情報（それまでのやりとり、日時、天気など）は、Google に送られます。無料枠では、送った内容が Google のサービスの改善に使われたり、人が読んだりすることがあります。個人情報や秘密は入力しないでください。
  • Gemini API の料金がかかった場合は、利用者の負担です。
  • API キーの管理は、利用者の責任で行ってください。このアプリは、キーを暗号化してこのパソコンの中に保存します。作者に送ることはありません。

4. 天気

  • 天気の情報は Open-Meteo から受け取っています（天気データ: Open-Meteo.com、CC BY 4.0、https://open-meteo.com/）。
  • 地域を探すときは入力した地名を、天気を調べるときは選んだ地域の位置（緯度・経度）を、Open-Meteo に送ります。

5. このパソコンに保存するもの

  • 予定、観測ノート、設定、会話の回数、動作の記録（ログ）を、このパソコンの中（%APPDATA%\desktop-pet）に保存します。API キーは暗号化して保存します。
  • これらを作者に送ることはありません。使い方を集める通信や、自動アップデートの通信もしません。

6. 保証しないこと

  • このアプリは、今あるままの状態で提供します。正しく動くこと、予定のお知らせが必ず時間どおりに出ることは保証しません。大事な予定は、ほかの方法でも管理してください。
  • Google（Gemini API）や Open-Meteo のサービスが止まったり変わったりして、会話や天気が使えなくなることがあります。
  • 不具合の修正、問い合わせへの返事、機能の追加などを約束するものではありません。
  • このアプリを使ったこと、または使えなかったことで起きた損害について、作者は責任を負いません。ただし、作者にわざと、または大きな不注意があった場合は除きます。

7. 権利

  • このアプリの権利は作者にあります（作者以外が作った部品はのぞきます）。
  • このアプリには、作者以外が作った部品（Electron、Chromium、koffi など）が入っています。これらには、それぞれのライセンスが適用されます。ライセンスの表示は、アプリと一緒に配っています。

8. 規約の変更

  • 作者は、この規約を変えることがあります。変えたときは、新しい版のアプリや配布ページでお知らせします。
