リマインダーなん？

予定の時間を知らせてくれる Windows 用のリマインダーアプリです。
キャラクターが出てきます。

ダウンロード

版 1.0.0 ・ Windows 用のインストーラー（約 201 MB）

ダウンロード・インストールした時点で、利用規約に同意したものとします。

スマホでは使えません。Windows のパソコンで開いてダウンロードしてください。

本物か確かめる（おすすめ）

インストーラーの SHA-256（ファイルの指紋）:

7c64dec4fe8fac41def2cc6d65921812d24f3649afbc34b3e7683c212b01f6a3

PowerShell で次のように実行して、出た値が上と同じか比べてください。違うときは、実行せずに削除してください。

Get-FileHash "$env:USERPROFILE\Downloads\ReminderNan-Setup-1.0.0.exe"

配布してくれた人から、別のメッセージで同じ値を受け取っている場合は、そちらとも比べるとより確かです。

インストール

  1. 上の「ダウンロード」のボタンから、インストーラーをダウンロードします。
  2. ダブルクリックして実行します。「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。このアプリには有料の電子署名を付けていないため、この画面が出ます。
  3. 利用規約が表示されるので、読んで「同意する」を押します。
  4. 誰のために入れるかを選ぶ画面では、そのまま（自分だけ）で進めます。この場合、管理者の権限は要りません。
  5. インストールが終わったら「完了」を押すと、アプリが起動します。スタートメニューとデスクトップに「リマインダーなん？」ができます。

動く環境

  • Windows 11（Windows 10 でも動く見込みです）
  • インターネットは、会話と天気を使うときだけ使います。

できること

  • 予定を登録すると、その時間に Windows の通知が出ます。キャラクターも吹き出しで知らせます。
  • 毎日・毎週などのくりかえしや、5 分前・10 分前・1 日前のお知らせもできます。
  • キャラクターがデスクトップを歩き回ります。その場に留まることもできます。トレイに入れられます。
  • Gemini API キーを設定すると、キャラクターと会話できます。会話で予定を登録したり、天気を聞いたりもできます。キーがなくても、ほかの機能はすべて使えます。

キャラクターの絵と動きについて

キャラクターの絵と動きは、Google の生成 AI（Gemini / Veo）で作った動画をもとに、切り出し・加工して作っています。観測ノートのメイキング動画は、作った動画そのものです。

天気データ: Open-Meteo.com（CC BY 4.0）

使っている部品: Electron・Chromium・koffi など。それぞれのライセンスの表示は、アプリと一緒に配っています。
